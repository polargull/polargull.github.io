01 / 关于我

后端的稳定性工程能力，是 Agent 时代最稀缺的底座

Agent 系统要走向生产，缺的不是会调模型的人，而是懂幂等、失败恢复、权限边界、可观测性与成本治理的工程师。这些正是我过去十年每天都在解决的问题。

我已经做到的

  • 主导分库分表扩容升级，支撑高峰期高并发交易，保障吞吐与数据一致性。
  • 自研链式节点审批流引擎，对接数十个子系统，日均万次流转，并完成 Spring Cloud 微服务化重构。
  • 设计本地消息表 + 定时补偿的可靠消息方案，实现待办状态 100% 同步至飞书审批中心。
  • 用 Redis 分布式锁、Lua 原子扣减、双缓冲白名单、RocketMQ 异步解耦，扛住 C 端瞬时高并发并防黑产刷单。

  • Tool Runtime：工具注册、Schema 校验、权限分级、调用审计与 Trace。
  • Agent Loop、状态机、Checkpoint 与 Sandbox 安全执行边界。
  • Context Engineering、Memory、RAG 混合检索与知识治理。
  • Multi-Agent 协作、Golden Dataset、回归评测与成本治理。

P2分布式审批流公共平台 · 独立设计与研发

2021.01 – 2025.01

背景 / 职责

自研「链式节点 + 条件分支」轻量审批流引擎，对接影城、卡、券、营销活动等数十个子系统，支撑全国影城日均万次审批流转。独立完成向 Spring Cloud 生态的重构迁移，并将审批待办从集团 OA 整体迁移至飞书三方审批中心。

关键方案

  • 设计通用微服务 RPC 契约与标准接口，实现审批流跨服务快速调用与解耦。
  • 待办同步：RocketMQ 监听事件 + 本地消息表 + 定时补偿 Task，解决网络波动，同步成功率 100%。
  • 跨域免登：UUID 映射安全重定向路由，对接集团统一身份认证，一键免登直达审批页。
  • 海量审批数据冷热分表，消除单表性能瓶颈。
工作流引擎可靠消息Spring Cloud免登安全

P3私域领券活动平台 · 主导设计与研发

2025.12 – 2026.01

背景 / 职责

面向集团私域的 C 端领券平台：运营按用户标签（企微 / 社群 / URM）配置差异化奖品，用户经小程序一键领奖。对接奖池服务（同步扣库存 + 异步发券）、会员与数美风控。负责活动详情与领奖两大核心接口。
